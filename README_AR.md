# نظام إدخال بيانات الأسر دون إنترنت — الإصدار 0.3.0

> نموذج أولي قيد التطوير. **لا تُدخل بيانات أسر حقيقية قبل الاختبار على جوالات حقيقية وقبل قرار الاستضافة** (انظر `docs/IMPLEMENTATION_REPORT_AR.md`).

## ما هو
تطبيق ويب (يعمل من ملف واحد `index.html`) لإدخال بيانات الأسر بصيغة الجهة المانحة (Sheet1) في الميدان **بلا إنترنت ولا كهرباء مستمرة**. البيانات تُحفظ على الجهاز نفسه (IndexedDB) مشفّرة، ويُصدَّر منها ملف Excel بالصيغة المطلوبة، وتُنقل بين الأجهزة بملفات (نسخة JSON موقَّعة بالبصمة، أو مشفّرة بكلمة سر).

## النسختان
| | الاستعمال | ماذا تفعل |
|---|---|---|
| `admin/index.html` | جهاز مدير النظام فقط | إنشاء النظام والمخيمات والمستخدمين والأدوار، تصدير «حزمة حسابات» موقّعة |
| `field/index.html` | أجهزة الباحثين والمشرفين | لا تنشئ نظاماً؛ تستورد الحزمة + «رمز المؤسسة» ثم تعمل |

## البدء السريع
1. **المدير:** افتح `admin` ← «إعداد نظام جديد» ← أنشئ المخيم والحساب. دوّن **رمز الاسترداد** و**رمز المؤسسة** (يُعرضان مرة واحدة/في شاشة المستخدمين).
2. أنشئ المستخدمين (المستخدمون ← ＋ مستخدم). تظهر **رسالتان** جاهزتان (اسم المستخدم / كلمة المرور المؤقتة) تُرسلهما من جهازك عبر قناتين مختلفتين.
3. **المستخدمون ← 📦 حزمة الحسابات** ← أرسل الملف للأجهزة الميدانية، وأعطِ الرمز شفهياً.
4. **الباحث:** يفتح `field` ← يستورد الحزمة ويكتب رمز المؤسسة ← يدخل بكلمة المرور المؤقتة ← يضع كلمته الخاصة.
5. **كل يوم:** «المزيد ← تصدير / نسخة احتياطية» ← نسخة مشفّرة بكلمة سر ← أرسلها للمشرف (واتساب/بريد/Drive/USB).
6. **المشرف:** «فحص ومعاينة» لكل ملف ← يحسم التعارضات ← تطبيق. بعدها تصدير Excel للجهة المانحة.

## ما يحميك من ضياع البيانات
- حالة الحفظ ظاهرة دائماً (✔ محفوظ 14:32)، وفشل الحفظ لافتة حمراء لا تُخفى.
- لقطات تلقائية للبيانات، وعند تلف الأخيرة تُستعاد لقطة سليمة (ولا يُستبدل شيء بقاعدة فارغة أبداً).
- مسودة النموذج تُحفظ أثناء الكتابة؛ زر الرجوع في الهاتف لا يغلق التطبيق.
- كل نسخة احتياطية تُفحص بإعادة قراءتها وبصمة SHA-256، وكل استيراد له معاينة ونقطة تراجع.
- **الحماية الحقيقية من ضياع الجهاز أو مسح المتصفح هي النسخة الاحتياطية خارج الجهاز.** والمدير يأخذ أيضاً «نسخة حسابات المدير».

## الأمان
- بيانات الأسر والملاحظات وسجل التدقيق **مشفّرة AES-256-GCM** بمفتاح لكل مستخدم مرتبط بكلمة مروره. نسيت الكلمة؟ المدير يعيد تعيينها دون فقد بيانات الموظف؛ والمدير يستعيد برمز الاسترداد.
- حزم الحسابات **موقَّعة** بمفتاح المؤسسة وترفض الأجهزة أي حزمة معدّلة أو قديمة أو من مؤسسة أخرى.
- سياسة أمان المحتوى تمنع الصفحة من الاتصال بأي خادم آخر. نسخة الإنتاج بلا `window.__app`.
- **حدود:** كلمة مرور ضعيفة تُخمَّن دون اتصال؛ جهاز مفتوح بيد غيرك؛ برمجية خبيثة. التطبيق المحلي لا يحمي من مالك الجهاز.
