camp-entry-app

Offline Family Data Entry Application.

Project Files

- "index.html" — Main application.
- "sw.js" — Service worker for offline support.
- "manifest.json" — Progressive Web App configuration.
- "README_AR.md" — Arabic documentation.
- "icon.svg" — Application icon.

Features

- Family data entry and validation.
- Local data storage.
- Excel export and JSON backup/import.
- User roles and permissions.
- Audit logging.
- Designed for offline use.

Important Notes

This project is a prototype. Data is stored locally in the browser and is not automatically shared between devices.

Security, data protection, and multi-user synchronization require further review and development.

Do not use real family records until the application's security and data protection have been properly reviewed.
